# קטלוג אביזרי וציוד Dell - כלי סינון ובקשת הצעת מחיר בוואטסאפ

כלי עצמאי (לא תלוי בוורדפרס) שמאפשר ללקוחות לסנן מתוך קטלוג אביזרי הדל
שמשווקים דרך הספק CMS (cms.co.il), ולשלוח בקשת הצעת מחיר מוכנה בוואטסאפ
ישירות מהמכשיר שלהם.

זהו פרויקט אחות ל[קטלוג מחשבי Dell](https://github.com/sariguy-prog/dell-catalog-app)
הקיים - אותו רעיון ואותה שיטת עבודה, אך עבור אביזרים וציוד (עכברים,
מקלדות, תיקים, אוזניות, מטענים, מצלמות, תחנות עגינה) במקום מחשבים.

הפרויקט מורכב משני חלקים:

1. **סקריפט סקרייפינג** (`scraper/scrape.js`) - אוסף את כל אביזרי ה-Dell
   מאתר CMS וכותב אותם ל-`site/data/products.json`.
2. **אתר סטטי** (`site/`) - HTML/CSS/JS פשוט (בלי React, בלי בילד),
   שקורא את `products.json` ומציג ממשק סינון וחיפוש עם כפתורי וואטסאפ.

---

## התקנה ראשונית

צריך [Node.js](https://nodejs.org) גרסה 18 ומעלה מותקן במחשב. לבדוק עם:

```bash
node --version
```

לאחר מכן, בתוך תיקיית הפרויקט (`dell-accessories-app`), מתקינים את התלויות
(פעם אחת בלבד, או כשעוברים למחשב חדש):

```bash
npm install
```

## איך מריצים את הסקרייפר (עדכון הקטלוג)

בכל פעם שרוצים לרענן את רשימת המוצרים (מוצרים חדשים, שינויי מלאי וכו'):

```bash
npm run scrape
```

מה קורה בפועל:

- הסקריפט עובר על **כל 9 המחלקות (departments)** של אביזרי Dell באתר
  cms.co.il - מטענים, רמקולים, תיקים, אוזניות, מצלמות, עכברים, מקלדות,
  סטים (מקלדת+עכבר) ותחנות עגינה - ובכל אחת על כל העמודים (מזהה אוטומטית
  כמה עמודים יש).
- בין כל בקשה לעמוד הבא יש המתנה של 1-2 שניות, כדי לא להעמיס על השרת.
- התוצאה נכתבת ל-`site/data/products.json`, קובץ אחד עם כל המוצרים מכל
  המחלקות (לכל מוצר יש שדה `category`).
- **אין מחירים בקובץ** - האתר של הספק לא חושף מחירים בלי התחברות, ולכן
  זה לא נאסף ולא אמור להופיע.

### בקרת תקינות (safety check)

הבדיקה מתבצעת **בנפרד לכל מחלקה**. אם באיזושהי מחלקה מספר המוצרים
שנאספו קטן משמעותית (פחות מ-90%) ממה שהיה בקובץ הקודם, הסקריפט **לא
מעדכן את המחלקה הזו** (הנתונים הישנים שלה נשארים כמו שהיו) - שאר
המחלקות כן מתעדכנות כרגיל. הוא ידפיס אזהרה בקונסול, וישמור את התוצאה
שכן נאספה לבדיקה ידנית בקובץ `site/data/products.rejected.json`.

## הוספת מחלקה (department) חדשה

המחלקות מוגדרות במערך `CATEGORIES` בתחילת `scraper/scrape.js`. כדי
להוסיף מחלקה חדשה:

1. באתר cms.co.il, בעמוד "אביזרי מחשב" מסונן ל-Dell
   (`https://cms.co.il/product-category/computer-acc/brand-dell/`), יש
   בצד רשימת "קטגוריות מוצרים" - כל קישור שם הוא כתובת מחלקה (משתמשים
   בגרסה עם הסיומת `-computer-acc` או בלי סיומת, לא בגרסה עם `-dell`,
   כדי שהמספרים לא יצטברו כפול).
2. מוסיפים ערך חדש למערך `CATEGORIES` עם `id`, `label` ו-`url`.
3. באתר עצמו (`site/app.js`), מוסיפים ל-`CATEGORY_CONFIG` ול-`CATEGORY_ORDER`
   את המחלקה החדשה (עם אותו `label`).

לאחר מכן `npm run scrape` יאסוף גם את המחלקה החדשה, והטאב שלה יופיע
באתר אוטומטית (טאבים מוצגים רק למחלקות שיש בהן בפועל מוצרים בנתונים).

## איך מעדכנים את "המוצרים המומלצים"

בקובץ `site/data/recommended-skus.json` יש רשימה פשוטה של מק"טים (SKU)
שמסומנים בתג "מומלץ" בכרטיס המוצר. אפשר לערוך את הקובץ ישירות בכל עורך
טקסט (גם Notepad), למשל:

```json
["570-ABHK", "580-AKGD"]
```

שינוי בקובץ הזה לא דורש הרצה מחדש של הסקרייפר - רק לרענן את דף האתר.

```bash

```

## פרסום ל-GitHub Pages

הפרויקט מתפרסם אוטומטית ב-GitHub Pages בכל `git push` ל-`main`, דרך
`.github/workflows/update-and-deploy.yml`. **חשוב:** בהגדרות הריפו
ב-GitHub (Settings → Pages) צריך להגדיר Source = "GitHub Actions" בפעם
הראשונה.

### מגבלה חשובה - הסקרייפר לא יכול לרוץ מהענן

בדיוק כמו בפרויקט האחות (dell-catalog-app) - cms.co.il חוסם בקשות
מכתובות IP של שירותי ענן (Cloudflare, HTTP 403). לכן `npm run scrape`
חייב לרוץ ממחשב "רגיל", ואת התוצאה דוחפים ידנית:

```bash
npm run scrape
git add site/data/products.json
git commit -m "עדכון קטלוג"
git push
```

### עדכון יומי אוטומטי (אופציונלי)

באותה שיטה כמו בפרויקט האחות - `scraper/register-daily-task.ps1` יוצר
משימת Windows Task Scheduler בשם `DellAccessoriesDailyUpdate` שרצה כל
יום ב-03:15 ומריצה `scraper/daily-update.ps1` (scrape + commit + push
אוטומטית אם הצליח).

```powershell
powershell -ExecutionPolicy Bypass -File scraper\register-daily-task.ps1
```

## מבנה הפרויקט

```
dell-accessories-app/
  package.json
  scraper/
    scrape.js               # סקריפט הסקרייפינג
    daily-update.ps1        # ריצה יומית אוטומטית (scrape + push)
    register-daily-task.ps1  # רישום משימה מתוזמנת ב-Windows
  site/                      # האתר הסטטי - זו התיקייה שמפרסמים
    index.html
    styles.css
    app.js
    data/
      products.json          # פלט הסקרייפר - לא עורכים ידנית
      recommended-skus.json  # רשימת מק"טים מומלצים - עורכים ידנית
```
